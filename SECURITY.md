# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| 0.1.x   | :x:                |

## Reporting a Vulnerability

Use GitHub's private vulnerability reporting: Security tab → Advisories → Report a vulnerability

### Response timeline

Acknowledge 48h, assess 7 days, fix critical within 30 days
